# 🏢 Shift Solutions - Employee Management App  

## 📌 Overview  
This is a team-based capstone project.
Shift Solutions is a cross-platform employee management application designed to help banquet employees at **Deerfoot Inn and Casino** manage their shifts efficiently.  
The app allows employees to view schedules, swap shifts, and communicate with their team in real-time.  

## 🚀 Features  
- **Employee Shift Management**: View upcoming shifts and request changes.  
- **Real-time Communication**: Send and receive messages related to work schedules.  
- **Secure Authentication**: Role-based login for employees and managers using Firebase Auth.  
- **Responsive Mobile UI**: Built with React Native & Expo for seamless cross-platform experience.  

## 🛠️ Tech Stack  
- **Frontend**: React Native, Expo, React
- **Backend**: Spring Boot, MySQL, Java
- **Authentication**: Firebase Authentication & Firebase Admin SDK  

## 📌 Installation & Setup  
To run this project locally, follow these steps:  

```bash
# Clone the repository
git clone https://github.com/teddy-1991/shift-solutions.git

# Navigate to the project directory
cd shift-solutions

# Install dependencies
npm install

# Run the development server
npm start
